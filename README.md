# MASTER PROMPT — KITKAT BALI TOUR

## Premium Bali Activities, Adventures, Wildlife Experiences & Private Tours

Build a complete, premium, modern, mobile-first travel and activities website for:

# 13. BOOKING STRATEGY

The primary booking channel is:

**WhatsApp**

Do not build a complicated booking engine initially.

Booking flow:

Experience page
→ Customer clicks Book via WhatsApp
→ Pre-filled message
→ Customer sends date + number of guests
→ KitKat Bali Tour confirms availability and price

WhatsApp message template:

Hello KitKat Bali Tour,

I would like to book:

Experience:
Date:
Number of guests:
Hotel / pickup location:

Please send me availability and the total price.

Make the WhatsApp number configurable from one central location.
